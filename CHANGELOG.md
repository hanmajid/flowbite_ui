# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Add `FlowbiteBreadcrumb` component.
- Add `FlowbiteToast` component.

## [0.0.5] - 11-09-2026
### Added
- Add `FlowbiteTheme.extension` static method.
- Add `FlowbiteBottomNavigation` component.
- Add `FlowbiteToggleInput` component (Advanced type).
- Add `FlowbiteJumbotron` component.

### Changed
- Migrate to `material_ui`.

## [0.0.4] - 10-09-2026
### Added
- Add `FlowbiteButtonGroup` component.
- Add `FlowbiteAccordion` component.

### Changed
- Refactor code with dot shorthands.

## [0.0.3] - 09-09-2026
### Added
- Add `FlowbiteAvatar` component.
- Add `FlowbiteAvatarGroupLabel` component.
- Add `FlowbiteAvatarGroup` component.
- Add `FlowbiteBadge` component.

## [0.0.2] - 09-09-2026
### Added
- Add `FlowbiteAlert` component.
- Add `FlowbiteSpinner` component.
- Add Widget Previews for existing components.

### Changed
- Update `README.md`.

## [0.0.1] - 08-09-2026
### Added
- Add `FlowbiteColorsExtension` and `FlowbiteTheme` classes.
- Add `FlowbiteColor` and `FlowbiteColors` classes.
- Add `FlowbiteFontFamily`, `FlowbiteFontSize`, and `FlowbiteFontWeight` classes.
- Add `FlowbiteButton` component.
- Add `FlowbiteOutlinedButton` component.
- Add `FlowbiteIconShape` component.
- Add `FlowbiteInputField` component.
- Add `FlowbiteInputLabel` component.
